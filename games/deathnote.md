# 데스노트

**게임 ID:** `deathnote`
**아이콘:** BOOK

## 개요

본명을 추리해 키라를 찾아내는 사회적 추리 게임입니다.
플레이어들은 밤과 낮을 반복하며 정보를 수집하고, 독대와 투표를 통해 서로를 의심하게 됩니다.

## 역할

| 역할      | 인원  | 설명                                             |
| ------- | --- | ---------------------------------------------- |
| 키라      | 1명  | 밤마다 플레이어의 본명을 조사하고 데스노트를 사용해 죽일 수 있습니다.        |
| 키라의 추종자 | 1명  | 키라의 정체를 알 수 있으며, 본명을 알고 있는 대상이 L인지 확인할 수 있습니다. |
| L       | 1명  | 플레이어의 본명을 조사하고 키라의 정체를 밝혀낼 수 있습니다.             |
| 경찰      | 1명  | 밤마다 플레이어의 본명 한 글자를 조사할 수 있습니다.                 |
| 탐정      | 1명  | 정확한 본명을 알고 있는 플레이어의 직업을 확인할 수 있습니다.            |
| 기자      | 1명  | 게임 중 한 번, 플레이어의 본명을 공개하는 기사를 작성할 수 있습니다.       |
| 연인      | 1명  | 본명을 알고 있는 대상과 커플이 될 수 있으며, 커플이 죽으면 대신 희생합니다.   |
| 시민      | 나머지 | 능력은 없지만 추리와 투표를 통해 키라를 찾아야 합니다.                |

## 진행 방식

1. 게임이 시작되면 모든 플레이어에게 직업과 세 글자의 본명이 부여됩니다.
2. 밤이 되면 플레이어들은 각자의 방으로 이동하며 직업 능력을 사용할 수 있습니다.
3. 밤이 끝나면 메인 홀로 이동하며 낮이 시작됩니다.
4. 낮에는 공개 토론, 독대, 투표를 진행할 수 있습니다.
5. 독대를 사용하면 특정 플레이어와 단둘이 대화할 수 있습니다.
6. 투표를 통해 특정 플레이어의 처형 여부를 결정할 수 있습니다.
7. 메인 홀에서 자신의 직업을 언급하면 본명의 글자가 공개되는 패널티를 받습니다.
8. 게임은 승리 조건이 충족될 때까지 밤과 낮을 반복합니다.

## 승리 조건

* **키라 승리:**

    * L이 사망한 경우
    * 시민 팀과 키라 팀의 생존 인원이 같아진 경우

* **L / 시민 승리:**

    * 키라가 투표로 처형된 경우
    * L이 키라의 정체를 밝혀낸 경우
